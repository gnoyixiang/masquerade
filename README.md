# Masquerade — User-Agent Switcher for Chrome

Masquerade is a small, local-only Chrome Manifest V3 extension for switching the User-Agent sent on HTTP(S) requests and, when explicitly enabled, the JavaScript identity of one tab. It includes presets for desktop, mobile, and tablet identities across Windows, macOS, Linux, ChromeOS, iOS, and Android, with Chrome, Edge, Firefox, Safari, Opera, and Samsung Internet coverage. Crawler identities are included for rendering and SEO checks.

## Install locally

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this project folder.
4. Pin Masquerade, choose a preset or enter a custom string, then reload the target page.

## Use

- **Network override** is global: it changes the server-facing request identity in all normal HTTP(S) tabs.
- **Full tab spoof** is independent: it uses Chrome's debugger API on the current tab so page JavaScript can see the selected `navigator.userAgent`. It stays on that tab and does not follow active-tab changes. Switching it on may require reloading the page.
- Both switches are independent: disabling Network override does not detach Full tab spoof, and enabling Full tab spoof does not turn on the global network switch.
- Presets are grouped by device class. Selecting one changes the saved identity while preserving both switch states; reload after enabling a mode to apply it.
- The Custom tab accepts a single-line string up to 512 characters. Draft text is saved locally as you type.
- The identity card derives the browser, device class, and OS from the selected string. Unrecognized custom strings are flagged so you can review them.
- **Copy** copies the identity shown in the readout. **Reload tab** reloads the active tab so its next requests use the new identity.

## How it works

The service worker stores the selected identity in `chrome.storage.local` and maintains one dynamic `declarativeNetRequest` `modifyHeaders` rule. Chromium-shaped presets get best-effort `Sec-CH-UA`, mobile, and platform alignment; other presets remove Chromium Client Hints. Full tab spoofing attaches only to explicitly selected tab IDs stored in session storage and sends only CDP's `Network.setUserAgentOverride` command. The badge is tab-aware: it appears only when the visible tab is affected by Network override or Full tab spoof. Nothing is sent to a remote service, and the extension does not read page content or browsing history.

The broad `http://*/*` and `https://*/*` host access is required for a browser-wide request-header switch. Chrome will not apply the rule to `chrome://` pages, the Chrome Web Store, or other browser-internal surfaces.

## Limitations

- Network override changes server-facing request headers; Full tab spoof additionally changes `navigator.userAgent` and best-effort `navigator.userAgentData` metadata for the selected tab. Neither mode changes screen metrics, fonts, IP address, TLS behavior, or other fingerprinting signals.
- Full tab spoofing changes `navigator.userAgent` and best-effort `navigator.userAgentData` metadata for Chromium-shaped presets, but it does not emulate every device signal. Firefox/Safari presets still run inside Chrome and may expose Chrome-specific properties.
- Client Hint changes are best effort and may be ignored or regenerated by Chrome, the site, or an intermediary.
- Rules affect new requests. Reload after switching, and use the built-in reload action when convenient.
- A preset's browser versions are representative examples. Update `presets.js` as browser versions move forward.
- The `"debugger"` permission is intentionally powerful. Masquerade uses it only to send `Network.setUserAgentOverride`; it does not inspect DOM, JavaScript, cookies, request bodies, or response bodies. Chrome may detach the debugger if DevTools is opened for the attached tab.

## Development checks

This project intentionally has no runtime dependencies or bundler:

```sh
npm test          # manifest, preset coverage, helper behavior, worker and debugger mocks
npm run build     # alias for npm test
npm run package   # creates masquerade.zip for sharing/loading
```

GitHub Actions runs these checks on pushes and pull requests targeting `main`.
The separate manual publish workflow uploads the validated package to the Chrome
Web Store and submits it for review. See
[docs/publishing.md](docs/publishing.md) for first-time setup and required
GitHub secrets.

The extension uses Chrome's documented [declarativeNetRequest API](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest), [Debugger API](https://developer.chrome.com/docs/extensions/reference/api/debugger), [permission model](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions), [MV3 CSP](https://developer.chrome.com/docs/extensions/reference/manifest/content-security-policy), and [Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs).
